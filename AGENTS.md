# Обязательные инструкции проекта

## Язык общения

- Все ответы пользователю в чате необходимо писать только на русском языке.
- Английский язык допустим только внутри кода, имён API, идентификаторов, путей, команд и дословных технических терминов, когда перевод ухудшает точность.

## Коммиты

- Все сообщения коммитов, включая заголовок и описание, необходимо писать только на русском языке.

## Работа с Unity

- При любой работе с Unity обязательно использовать MCP-сервер `unityMCP`.
- Это правило распространяется в том числе на UI, сцены, префабы, GameObject, компоненты, ассеты, материалы, камеры, настройки проекта, консоль, компиляцию, тесты и визуальную проверку результата.
- Перед изменениями читать через `unityMCP` релевантные ресурсы и состояние Unity Editor. После изменений проверять результат через `unityMCP`, включая состояние компиляции, консоль, тесты и снимки экрана, когда это применимо.
- Не считать работу с Unity завершённой без проверки через `unityMCP`. Если сервер недоступен, явно сообщить об этом пользователю и не подменять обязательную Unity-проверку неподтверждёнными предположениями.

## Платформа и SDK (Яндекс.Игры и YG2)

- Проект разрабатывается под платформу **Яндекс.Игры**.
- Необходимо строго следовать правилам платформы и соблюдать все её требования (документация: https://yandex.ru/dev/games/doc/ru/).
- В проекте используется плагин **YG2**. При реализации любого функционала, связанного с платформой (реклама, сохранения/облако, лидерборды, авторизация, покупки, локализация и др.), обязательно использовать API плагина YG2 (документация: https://max-games.ru/plugin-yg/doc/).

# Code Style

## Структура скрипта (строгий порядок)

1. `public event`
2. `public` поля
3. `[SerializeField] private` поля
4. `private` поля
5. Свойства
6. Unity-методы (`Awake` → `OnEnable` → `Start` → `Update` → `FixedUpdate` → `LateUpdate` → `OnDisable` → `OnDestroy`)
7. Публичные методы
8. Приватные методы

## Именование

| Что | Как |
|-----|-----|
| Публичные поля | `camelCase` |
| Публичные события | `PascalCase` |
| `[SerializeField] private` | `_camelCase` |
| Приватные поля | `_camelCase` |
| Свойства | `PascalCase` |
| Параметры методов | `camelCase` |

## Комментарии

- **Без `/// <summary>`**
- Комментарии только для сложной/неочевидной логики
